# 아빠 TV — 시험판
삼성 갤럭시용 Android WebView 시험 앱입니다. 사이트 주소를 앱 안에서 직접 변경할 수 있으며, 원본 사이트에서 검색/회차를 선택합니다. 영상 플레이어가 전체화면을 지원하면 앱에서도 전체화면을 표시합니다.

**주의:** Smart View 자동 연결이나 안내문 제거, 원격 주소 관리, 별도 검색/회차 UI는 아직 구현되지 않았습니다. 영상 사이트에서 WebView를 차단할 수도 있습니다.
GitHub Actions의 **Build Dad TV APK** 워크플로를 수동 실행하고 Artifacts에서 dad-tv-debug-apk를 받으세요.
